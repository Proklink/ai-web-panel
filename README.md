# Webpanel

Веб-интерфейс для диалогов с Claude Code с ваших устройств. Каждый диалог — отдельная tmux-сессия на сервере.
Подробный контекст, статус и планы — в [PROJECT.md](PROJECT.md).

## Требования

- Ubuntu 24.04+ (проверено на 26.04), root.
- Установленный и залогиненный Claude Code (`/root/.local/bin/claude`).
- Остальное (PostgreSQL, Node.js, Caddy, tmux, Python venv) ставит скрипт.

## Установка

```bash
cd /root/workspace/webpanel
sudo ./webpanel.sh install                         # HTTPS на внешний IP (самоподписанный сертификат)
# или
sudo ./webpanel.sh install --domain chat.example.com   # с доменом и Let's Encrypt
```

После установки:

1. `./webpanel.sh setup-code` — код первичной настройки.
2. Откройте `https://<IP сервера>` (браузер предупредит о самоподписанном сертификате — это ожидаемо),
   создайте администратора с этим кодом. Вход без сертификата устройства открыт на 60 минут и только для админа.
3. «Управление» → «Доступ и сертификаты устройств» → выпустите сертификат для своего устройства,
   установите `.p12` (инструкции для Android/iOS/Windows/macOS/Linux показываются при выпуске), перезапустите браузер.
4. Для других устройств: выпустите сертификат + «Приглашение», установите сертификат на устройство и зарегистрируйтесь
   с кодом приглашения.

## Повседневные команды

Все команды и примеры: **`./webpanel.sh help`**

| Команда | Что делает |
|---|---|
| `./webpanel.sh status` | состояние служб и открытые диалоги |
| `./webpanel.sh logs -f` | журнал в реальном времени |
| `sudo ./webpanel.sh restart` | перезапуск веб-сервера (диалоги не прерываются) |
| `sudo ./webpanel.sh update` | пересобрать и перезапустить после изменения кода |
| `./webpanel.sh sessions` | какие диалоги в памяти и сколько занимают |
| `./webpanel.sh attach <ID>` | подключиться к tmux-сессии диалога (выход: Ctrl+B, D) |
| `sudo ./webpanel.sh passwd <логин>` | сбросить пароль |
| `sudo ./webpanel.sh open-window 30` | временно пустить админа без сертификата (если потерян доступ) |
| `sudo ./webpanel.sh backup` | резервная копия БД и данных |
| `sudo ./webpanel.sh stop --all` | остановить всё, включая открытые диалоги |

## Разработка

```bash
sudo ./webpanel.sh stop
sudo ./webpanel.sh dev              # бэкенд на 127.0.0.1:8100 с автоперезагрузкой
cd frontend && npm run dev          # фронт на 127.0.0.1:5173 с прокси /api → 8100
```
